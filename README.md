# 🎮 Party Craft OS - Sistema Operacional de Jogo

Um jogo imersivo inspirado em Party Craft com seu próprio **Sistema Operacional completo**, incluindo navegador funcional, loja de aplicativos, mini-games e muito mais!

## 🌟 Características Principais

- **📱 Sistema Operacional Completo**: Desktop com janelas, ícones, widgets
- **🌐 Navegador Funcional**: Acesso a sites fictícios e conteúdo do jogo
- **🛒 App Store Integrada**: Baixe e instale aplicativos
- **🎮 Mini-Games**: Party Craft com múltiplos mini-games
- **☎️ Sistema de Telefone**: Chamadas, mensagens, contatos
- **📸 Câmera & Câmera de Fotos**: Tire fotos no jogo
- **🎵 Música & Som**: Sistema de áudio completo
- **👥 Multiplayer Local**: Suporte para múltiplos jogadores

## 🎯 Como Jogar

1. Abra o jogo
2. Explore o SO - desktop, apps, etc
3. Use o navegador para pesquisar informações
4. Acesse a App Store e baixe aplicativos
5. Jogue mini-games de Party Craft
6. Progresse e desbloqueie novos conteúdos

## 🚀 Tecnologias

- **HTML5** - Estrutura
- **CSS3** - Design responsivo
- **Vanilla JavaScript** - Lógica sem dependências externas
- **Canvas API** - Gráficos dos mini-games
- **Web Audio API** - Sistema de som
- **LocalStorage** - Persistência de dados
